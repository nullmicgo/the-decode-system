the setup

set it up yourself

00

what you need

  • an apify account to pull instagram and tiktok videos (apify.com)
  • a typesafe account for jev, the ai that does the sorting (typesafe.ai). grab an api key
  • claude code to build and run it for you. you don't need to know how to code
  • a list of creators posting for the brand, or the brand's hashtag
01

pull every video on the deal

use apify's instagram reel scraper (and the tiktok scraper if the deal runs there too). give it every creator's handle and how many recent videos to grab. you get back the video file, caption, views, likes, comments and post date for each one.

tool: apify reel scrapercost: under 20 cents per 100 videos

go wide. the point is seeing the whole deal, not just the creators you already watch. invo had 99 creators posting.

02

get the words out of each video

transcribe each video with whisper. it runs free on your own computer. keep the on-screen text and caption too, because a lot of ugc hooks live in the text overlay, not the voice.

tool: whispercost: free
03

write down the formats you see

scroll the deal for ten minutes and name the formats people keep repeating. 5 to 12 is plenty. describe each in one line, and always add a "none of these" option so nothing gets forced into the wrong bucket.

  • "3 websites they're gatekeeping" + comment keyword
  • "unethical ways to make money, part n"
  • "15 minutes on the clock" app walkthrough
  • relatable trader meme skit

these are the real invo formats. yours will be different for every brand.

04

let jev sort every video

jev doesn't write anything back. you give it the video's words and your list of formats, and it picks one and tells you how sure it is. that's why it's fast and almost free: you pay for what it reads, and its answers cost nothing.

// one request per video. this is the real shape of jev's api
POST https://api.typesafe.ai/v1/systemone
Authorization: Bearer YOUR_TYPESAFE_KEY

{
  "model": "jev-latest",
  "state": {
    "transcript": "if you're broke right now, these 3 websites...",
    "on_screen_text": "3 websites they're gatekeeping",
    "caption": "comment SITES and i'll send them"
  },
  "questions": {
    "format": {
      "type": "choice",
      "instructions": "Which of this brand deal's formats is this video? Pick none if nothing fits.",
      "criteria": {
        "gatekeeping_websites": "lists 3 websites they're gatekeeping, ends on a comment keyword",
        "unethical_ways": "'unethical ways to make money part n' series",
        "clock_walkthrough": "15 minutes on the clock, walks through the app live",
        "trader_skit": "relatable trader meme skit, acted scene",
        "none": "doesn't match any format above"
      }
    },
    "shows_brand": {
      "type": "noul",
      "instructions": "Does this video actually show or name the brand's app?"
    }
  }
}

// what comes back
{ "answers": {
    "format": { "type": "choice", "choice": "gatekeeping_websites", "confidence": 0.93 },
    "shows_brand": { "type": "noul", "noul": 0.88 } } }
tool: jev by typesafecost: about 4 cents per million tokens it reads, answers are free

the "shows_brand" question is a free filter. it throws out videos that tag the brand but never actually show it.

05

find the winners

group the videos by format and take the median views, not the average. one viral video can make a bad format look great on average. then divide by the whole deal's median to see how many times better each format does.

ignore any format with under 5 videos. on invo, "it's 3am and i just found the easiest way to make money" had the highest median, but only 4 videos. too few to call.

06

draw the picture

put every video on one chart: views across the bottom, likes up the side, both on a log scale. use each video's thumbnail as its dot. the deal turns into a funnel, and when you click a format, its videos light up and you see where they land.

add a side panel that opens any video's hook, numbers and script, and a table ranking every format. that's the whole decode page from the video.

questions

quick answers

do i need to know how to code?

no. paste the prompt into claude code and answer its questions. it writes and runs everything. you just fill in the brand, the creators and the formats.

what is jev, and why not just use chatgpt?

jev is an ai from typesafe built to make one clear call at a time: pick from your list, yes or no, or a score. it gives you a typed answer with a confidence number instead of a paragraph, so you can sort thousands of videos fast and cheap, and the results drop straight into a chart.

can i run it on my own account instead of a brand deal?

yes. swap the list of creators for just your handle and use your own formats. you'll see which of your formats actually carry your views.

how often should i run it?

once when you land a deal, then every week or two. formats wear out, and new ones show up that you'll want to jump on early.
